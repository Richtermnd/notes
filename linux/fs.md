# fs

Файловая система - система, отвечающая за хранение файлов на диске, состоящая из двух частей:
- программа решающая куда писать файлы, откуда читать
- сами файлы, метаданные, иноды

Первая часть - модуль ядра.
Вторая - хранится на самом диске.


## Типы FS
- FAT32
- exFAT
- NTFS

FS разбивает диск на *секторы*, файлы хранятся в секторах

> [!NOTE]
> Сектор - физический адрес на диске (на современных дисках - 4КБ)

> [!NOTE]
> Сектора, на которых записан один файл, не обязательно находятся рядом друг с другом.


> [!TIP]
> `sudo fdisk -l /dev/<disk>` посмотреть информацию по диску


## LVM

Logic Volume Manager позволяет создать общее пространство памяти из нескольких разделов и дисков.


Диски и разделы становятся - physical volume (pv)
Общее пространство, сформированное pv - volume group (vg)
Разделы внутри этой групы - logical volume (lv)

> [!NOTE]
> pv -> vg -> lv

### commands
- {pv,vg,vl}create
- {pv,vg,vl}display
