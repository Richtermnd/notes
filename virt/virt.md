# Virtualization

Тут преимущественно про libvirt с qemu+kvm

## Технологии

### kvm - kernel virtualization module
Часть ядра Linux которая отвечает за виртуализацию (эмуляцию железа) на уровне ядра ОС.

### qemu
Программа, позволяющая создавать VM и управлять ими.

### libvirt
Унифицированный интерфейс для инструментов виртуализации.
[libvirt](https://libvirt.org/)

### Диски.
Изначально мы имеем .iso образ с ОС, которую хотим установить. Установить её надо на какой-то диск. Для этого мы создаем диск в одном из двух форматов - raw или qcow2 (про их отличия отдельно, но вкратце - используй qcow2 всегда).

```bash
qemu-img create -f {raw,qcow2} disk [SIZE]
qemu-img create -f qcow2 disk.qcow2 20G 
qemu-img create -f raw disk.raw 20G 
```


### libvirt
Посколько qemu это какой-то кошмар в плане API, будет использоваться libvirt.
libvirt предоставляет унифицированный интерфейс для разных бекендов виртуализации, а так же удобный API.

libvirt определяет абстракции, с которыми он работает. Тут перечислены только те, которыми я умею пользоваться/понимаю принцип их работы.
- domain
- pool
- volume
- network
